本仓库携带的 NotoSansSC-Regular.otf 并非上游原版，而是经 pyftsubset
子集化后的裁剪版本：

  · 字符集   GB2312 全集（一级 + 二级共 6763 个汉字）
             + ASCII / Latin-1
             + 通用标点（U+2000–U+206F）
             + CJK 标点（U+3000–U+303F）
             + 全角字符（U+FF00–U+FFEF）
             + 计量单位（U+33A0–U+33C0，如 ㎡）
             + 带圈数字（U+2460–U+24FF）与箭头（U+2190–U+21FF）
  · 体积     7.95 MB → 1.71 MB（降 78.5%）
  · 用途     仅供 src/app/api/og 的动态 OG 分享图渲染中文，
             使服务端函数包体积可控（Next.js 的 output file tracing
             会把该字体打进部署产物）。

子集化属于 OFL 1.1 定义中的「Modified Version」。说明：

  · 上游 Noto CJK 的 OFL 未声明 Reserved Font Name，因此修改版本
    无需更名，可以继续使用「Noto Sans SC」这一字体名。
  · OFL 1.1 第 2 条要求分发时附带版权声明与许可证全文 —— 即本文件。
  · OFL 1.1 第 5 条要求修改版本整体仍以本许可证分发，不得附带其他许可。
    本仓库中的字体文件因此继续适用 OFL 1.1。

已知限制：若 OG 图标题使用了 GB2312 之外的生僻字（如「𠮷」等
扩展区汉字），该字将渲染为空白。可通过重新生成更大的子集解决，
生成方式见 docs/03-开发计划.md 的相关任务说明。
