# 动态内容契约（社区动态：列表 + 详情）

> 代码事实源：`src/lib/opc/news-runtime.ts`；契约测试：`test/opc-news-runtime.test.ts`。
> 区块级运行时化（统计墙/伙伴墙/课程卡/智能体目录/供需榜）见 `docs/17-区块运行时化契约.md`；
> 总契约见 `docs/19-全站复刻与参考站快照管线.md`。
>
> 2026-10-26 版本是「新闻 / 活动**双列表** + 构建期文本占位符」模式；
> 2026-11-10 起：单条 `/news`（活动是类目），定位方式从**文本占位符**改为
> **`data-opc-block` 标记**（与区块运行时化统一），卡片 DOM 换成参考站的 `.nitem` 折叠卡。

## 0. 类目词表（2026-11-10 起）

分类的**唯一事实源是后台** `src/lib/admin/news-schema.ts` 的 `NEWS_CATEGORIES`：

```
行业观察 / 政策资讯 / 赛事活动
```

它必须与前台 `/news` 的筛选 chips（`data-news-filter`）**逐字一致** ——
否则会出现「运营发不出这类文章（zod 枚举拒）」或「点了某个 chip 一篇都没有」。
旧站的「沙龙 / 活动 / 资讯 / 社区」是双列表（/newslist + /activitylist）时代的词表，
随 `/activitylist` 下线而废弃。

## 1. 列表：/news

- 容器：`div.newslist[data-opc-block="news-list"]`（编译期打标记）。
- 运行时：DB（`news_posts`）成功 → 渲染 DB 卡片；未配库 / 查询异常 → **空列表**
  （容器保留、内容清空）。DB 是唯一事实源，**不回落烘焙快照**。
- 卡片形态沿用参考站：**折叠卡**（点 `.nitem__hd` 展开 `.nitem__body`），
  同时标题链接到 `/newsdetail?id=<slug>`，保证详情页仍是独立可索引页面。

### 卡片 DOM 契约

```html
<article class="nitem rv" data-opc-id="<slug 数字部分或 slug>" data-opc-category="<类目>">
  <div class="nitem__hd">
    <div class="nitem__date"><b>DD</b><span>YYYY-MM</span></div>
    <div class="nitem__ph"><img src="<cover_url>" alt="<标题>" loading="lazy" decoding="async"></div>
    <div class="nitem__bd">
      <span class="ntag">类目</span>
      <h3><a href="/newsdetail?id=<id>">标题</a></h3>
      <p>摘要</p>
    </div>
    <span class="nitem__more"><svg …></svg></span>
  </div>
  <div class="nitem__body">
    <p>首段正文</p>
    <p class="nsrc"><b>阅读全文：</b><a href="/newsdetail?id=<id>">标题 ↗</a></p>
  </div>
</article>
```

- 全部文本经 `escapeText`（`& < > " '` 全套）。
- `cover_url` 缺省回落站内占位图 `/opc/reference/img/news-wuzhen-opc.jpg`；
  非 `/` 开头且非 https 的地址一律回落（不渲染外链图）。
- 日期：`published_at` → `YYYY-MM-DD` → 拆成「日」与「年-月」两段（参考站卡片形态）。

## 2. 详情：/newsdetail?id=

1. id 为数字 N → 查 DB slug=`opc-N`；id 为 slug 形态 → 查 DB 该 slug；
2. DB 正文（body 数组）注入 `generated/article-shell.json`：
   纯文本段转义为 `<p>`；富文本 HTML 经 `sanitize-html` 允许列表净化
   （移除脚本、事件属性、危险协议与协议相对 URL）；标题与日期始终转义；
3. 未配库 / 查询异常 / 库内无此文 → **404**（不再回落遗留 `details.json`）。

`article-shell` 的占位符：`__OPC_TITLE__` / `__OPC_DATE__` / `__OPC_ARTICLE__`。

## 3. 数据来源

- 参考站的 5 篇动态由 `scripts/seed-reference-content.mjs` 灌入 `news_posts`
  （slug `opc-ref-01` … `opc-ref-05`，正文段落来自参考站 `.nitem__body`，
  封面指向 `/opc/reference/img/*`）。
- 脚本**幂等**：表里有数据就整表跳过，不覆盖运营后续修改。
- 运营发布的内容在后台「社区动态」模块维护，保存后 `revalidatePath('/news')` 立即生效。

## 4. 发布联动矩阵（revalidatePath）

社区动态发布 / 下架 / 删除时失效：`/news`、`/newsdetail`、`/`（首页动态四卡）、`/sitemap.xml`。

## 5. sitemap

`/newsdetail?id=` 条目读 DB 已发布文章（id 取值与卡片 `data-opc-id` 同款）；
无库 / 异常时**不含文章条目**。
