# OPC Store 科技蓝全站复现

2026-10-22。参考站为 https://opcstore.com/webNew/index.html#/ 。本轮取代原首页与栏目布局方案，复现主站公开布局与原文，配色改科技蓝。未进行线上部署。

共20个模板。兼容原站大小写路径及 `/webNew/index.html#/…`，内部导航转换成本地路径。原导航中的算力超市等独立站点保留外链。

公开内容取全：233个AI工具条目、44个南京社区、88条新闻、22条供需、13门课程、22条活动、13条社区资讯，合计158条详情。列表按源顺序保留，查看更多会显示后续条目。城市专区使用10座城市的原始文案。

## 实现与内容边界

- 页面HTML在生成期使用标签、属性、URL和内联样式白名单净化，移除源脚本、事件与嵌入内容；保留布局所需作用域属性。
- 页面与详情由Next.js服务端渲染；小型客户端适配层负责筛选、搜索、分页、菜单、弹窗、密码显示和表单校验。
- 科技蓝CSS限定于 `.opc-replica`，动画命名与图标字体独立，避免污染现有后台。
- 全部页面图片引用均本地化。875个素材URL映射为591个真实镜像与284个占位映射：226个原站图标源返回404，58个站外正文图下载被自动审批拒绝。正文文字完整保留，受限请求没有被绕过。
- 自动审批拒绝的正文配图涉及微信图片域和带令牌参数的飞书流式地址。构建清单移出public，仅静态素材和CSS对浏览器可见。
- 图片经本地压缩后素材约44MB，最大单图约381KB；CSS约390KB，本地显示字体与图标字体均无需远程加载。
- 账号、短信验证码与申请后端未接入，界面明确显示未配置状态，不向参考站提交，也不伪报成功。原站需登录的申请和个人页保留登录门槛。
- 现有管理员权限、线索API和数据库规则未修改。此轮验收不代表数据库、账号或线上业务验收。

## 本地运行与再生成

```bash
pnpm dev
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

生成数据采用已保存的公开源输入，不运行第三方JavaScript：

```bash
pnpm opc:styles   # 离线使用缓存素材与保存CSS重新生成主题
pnpm opc:content  # 重新净化HTML、补齐列表与生成详情
```
