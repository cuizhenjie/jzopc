## 1. 模式总述

```
请求 → ISR 缓存（300s）→ 未命中/过期 → getRuntimeReplicaPage(pathname)
                                        ├─ getReplicaPage 取烘焙快照（页面外壳/版式）
                                        ├─ 按区块查 DB（表级查询，无用户输入拼接）
                                        └─ applyXxx 替换区块（空行 → 置空该区块；首页 banner 见下表例外）
后台保存 → resource-api 写库成功 → revalidatePath(目标页) → 下一次请求即再生成
```

空区块语义（区块级，互不牵连）：

| 状态 | 行为 |
|---|---|
| 未配置 Supabase / 查询 error / 查询 throw | loader 返回 `[]` → 区块**置空**（容器保留，内容清空）。首页 banner 例外：返回 `unavailable`，**保留烘焙首屏图** |
| 查询成功但结果为空（或过滤后为空） | 同上，区块置空；`/agent` 例外——重建为「全部」chip + `共 0 个智能体`。首页 banner 查询成功但没有可用图时清空 `home-banners` 内部 |
| 替换过程抛异常（数据形状意外） | 装配层 try/catch → 保留已替换进度继续返回，**永不 500**（bug 级保护，非数据兜底） |
| 区块标记在快照中不存在（产物结构变更） | 该区块原样保留（外壳完整性保护） |

## 2. 区块清单（页面 × 表 × 标记 × 失效链）

标记由 `scripts/build-opc-reference.mjs` 的 `markDynamicBlocks()` 在编译期打在容器上。

| 页面 | 区块 | DB 表 | 标记 / 定位 | admin 模块 → revalidatePath |
|---|---|---|---|---|
| `/` | 首屏背景轮播 | `home_banners` | `div[data-opc-block="home-banners"]` | 首页 Banner → `/` |
| `/` | hero 统计数字墙 | `site_stats` | `div[data-opc-block="home-stats"]` | 统计数字 → `/` |
| `/` | 社区动态四卡 | `news_posts` | `div[data-opc-block="home-news"]` | 社区动态 → `/`、`/news` |
| `/about` | 生态伙伴墙 | `partners` | `ul[data-opc-block="partner-grid"]` | 合作伙伴 → `/about` |
| `/academy` | 课程体系卡 | `courses` | `div[data-opc-block="course-grid"]` | 课程 → `/academy` |
| `/agent` | 智能体网格 | `agents` | `div[data-opc-block="agent-grid"]` | 智能体 → `/agent` |
| `/agent` | 分类 chips | `agents` | `#agentChips`（按 id 定位） | 智能体 → `/agent` |
| `/agent` | 结果计数 | `agents` | `#agentCount`（按 id 定位） | 智能体 → `/agent` |
| `/news` | 动态列表 | `news_posts` | `div[data-opc-block="news-list"]` | 社区动态 → `/news` |

页面装配：`/`、`/about`、`/academy`、`/agent`、`/news` 为**显式 ISR 300 路由**；
`/market`、`/health`、`/empower`、`/growth`、`/apply` 为纯快照路由（无动态区块）。

## 3. 定位算法

`src/lib/opc/dom.ts` 提供两个原语：

- `replaceBlockInner(html, marker, tagName, buildInner)`：正则命中
  `<tagName … data-opc-block="marker" …>` 的开标签，从开标签之后按 `<tagName` / `</tagName>`
  字面 token 计数配平到闭标签，**只替换内部**；开闭标签本身（含 class/style/aria 属性）原样保留。
- `replaceElementInnerById(html, id, tagName, buildInner)`：按 id 定位单个元素并替换其内部
  （用于 `#agentChips` / `#agentCount` 这类短标签）。

守卫（由 `test/dynamic-blocks.test.ts` 锁定）：

1. 各标记在对应页 HTML 中**恰好出现一次**；
2. 标记缺失（结构变更）→ 原样返回，宁可不动不可截断；
3. 闭标签缺失 → 原样返回。

## 4. 各区块渲染契约

### 4.0 首页首屏轮播（`home-banners`）
- 只替换 `.hero__bg` 内部的 `img.hero__slide`。口号、角标、统计墙仍是烘焙内容。
- 查询成功才替换。第一张带 `is-on`、`fetchpriority="high"`，不设 `loading="lazy"`；后面的张设 `loading="lazy"`。
- 开标签补 `data-hero-live`，停掉参考站两张图的 CSS 交叉淡入，只显示 `.is-on`。
- 不安全的图片地址（非站内根路径、非 https）整张丢掉。可用图为 0 时容器留空。
- 未配库或查询失败不调用替换，烘焙的两张图留在页面上。
- 左右按钮和底部步骤条由 `ReferenceInteractions` 挂到 `.hero` 上，不写进区块 HTML。一张图时不显示控件。自动播放 8 秒；鼠标或键盘停在控件上、以及 `prefers-reduced-motion` 时暂停自动播放，手动切换仍可用。

### 4.1 首页统计墙（`home-stats`）
- 卡结构：`div.hstat > b（含可选 i）+ span`，对齐参考站 `.hstat` 样式契约。
- 数值口径：`value` + `suffix`；`+` 等符号型前缀单独用 `<i>` 着色（参考站 `.hstat b i`），
  单位（㎡ / 家）留在数字后。

### 4.2 首页动态四卡（`home-news`）
- 卡结构照抄参考站 `.ncard`：`ncard__hit`（整卡链接到 `/newsdetail?id=<slug>`）、
  `ncard__ph`（封面）、`ncard__bd`（标题 / `ncard__meta` 类目+日期 / 摘要）。
- 只取最新 4 条；DB 空 → 四卡区置空。

### 4.3 生态伙伴墙（`partner-grid`）
- 卡结构：`li.partner-wall__i`，有合法 `logo_url` 渲染图片，否则渲染文字卡
  （`span.partner-wall__txt`）——本项目**不**跳过无 logo 的行（参考站的伙伴区是品牌字排版）。
- 整墙接管语义：有合法行即整墙替换，无行即整墙置空。

### 4.4 课程体系卡（`course-grid`）
- 卡结构：`a.ac-crs__i > .ac-crs__ph（封面）+ .ac-crs__bd（标题 / 说明 / tag）`。
- 配图回落：合法 `cover_url` → 站内占位图（`/opc/reference/img/course-aigc.jpg`）。

### 4.5 /agent 智能体目录（`agent-grid` + `#agentChips` + `#agentCount`）
- **整体重建**：chips、计数、网格三处一起换。
- chips 的 `data-cat` 与卡片的 `data-opc-categories` **同源**（都是后台分类 slug），
  客户端筛选是同值比对，不需要别名表；chip 文案用中文名（`site/config.ts` 的 `agentCategories`）。
- 分类 label 取 `src/lib/site/config.ts` 的 `agentCategories`（与后台表单选项同源）；
  库里出现未知 slug 时直接用 slug 原文兜底。
- 卡结构：`a.acard > .acard__top（头像/首字母 + 名称）+ p（描述）+ .acard__url（域名）`。
- 外链仅 `https`（`isSafeExternalUrl`），不合法的行整卡跳过。

### 4.6 /market 社区供需榜 —— 已下线（2026-11-10）
应用户要求移除「COMMUNITY BOARD · 社区供需榜」模块，该板块从**编译期注入**
（`scripts/build-opc-reference.mjs` 的 `markDynamicBlocks`）、**运行期接管**
（`applyMarketItems` / `loadMarketItems`）与**扩展样式**
（`.sd-board` / `.sd-card`）三处一并下线。`/market` 现为纯快照路由：
只保留参考站原有的发布表单（提交后进后台线索池 `leadType=market`）。
`market_items` 表与后台「供需发布」模块保留，但不再在前台展示。

## 5. 安全口径

- 所有 DB 文本（标题/摘要/名称/标签/分类）渲染前一律过 `escapeText`（`& < > " '` 全套）。
- 图片 URL：仅 https 外链或本站根相对路径（拒 `//`、控制字符、反斜杠）；
  智能体外链同口径（拒 http/userinfo）。
- 查询全部为静态表名/列名的表级查询，无用户输入拼接。
