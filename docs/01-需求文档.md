### 1.5 竞品定位裁决（v1.1 增补，依据 `docs/05`）

> 完整推导见 [`docs/05-全国OPC社区与商业楼宇平台竞品审查.md`](./05-全国OPC社区与商业楼宇平台竞品审查.md)（结论层）与 [`docs/05-...竞品事实.md`](./05-全国OPC社区与商业楼宇平台竞品事实.md)（证据层，1244 行）。

**行业坐标**：全国已有 20+ 城市出台 OPC 专项政策、65 城落地 426 家社区；头部社区（经开区 8 家认证、大兴绿地、绿洲 CO-LAB、呼和浩特云港、南京同橙）的官方叙事**无一例外是「免费/免租/补贴」**。集智体量（3000㎡）打不过经开区 3 亿补贴池，**不参与面积与价格竞争**。

**行业真相**：媒体与从业者共识——「空间不是核心，订单和交付才是」（经济观察报采访）。集智必须把叙事从「功能清单」换成「链路闭环」。

**裁决一 · 唯一能赢的叙事**
> **「不只是八个服务，是一条从工位到订单的链」**
> 竞品结构是空间+算力+课程+活动的**四个并列块**；集智的结构是空间 → 算力 → 智能体 → **订单** → 流量 → 资本的**一条链**，且订单是终点而非又一个并列项。

**裁决二 · 首页必须突出的 5 个信息点**（已落进 §4 信息架构）

| # | 信息点 | 落地位置 |
|---|---|---|
| 1 | 3000㎡ 实体空间 + 办事窗口在楼里 | Hero / 关于页 |
| 2 | 八大赋能是一条链，不是八个功能 | 首页八大赋能区**前置链路视觉**（`EmpowerChain`） |
| 3 | 订单与流量双入口 | 供需市场 + 流量赋能 |
| 4 | 四条数据指标 | 首页指标条 |
| 5 | 丰台区位与 30 分钟落地效率 | 关于页 / 申请入驻 |

> **禁止**：首页不出现「免租多久」「补贴多少」——集智要卖链条效率，不卖价格。

**裁决三 · 落地后的差异化动作**（新增于本版）

| 动作 | 竞品依据 | 官网落地 |
|---|---|---|
| 入驻后可做什么写清楚 | 行业诊断「签约前热情、签约后冷淡」 | `/apply` 的「入驻之后，这 8 件事都能在社区里做」模块 |
| 订单做成可验证的公开资产 | 全行业无一家公开订单墙 | 二期：社区订单墙（本期数据待业务方提供） |
| 3D/粒子作为主视觉 | 7 家楼宇平台仅 1 家用粒子；**无一家 OPC 社区官网做过 3D** | 已实现自写 GLSL 粒子 Hero + 五级降级 |

### 1.6 八大赋能 → 一条链：卡片模型的修订（2026-10-20）

**变更前**：首页有 **8 张完全同款**的赋能卡片（同一圆角、同一阴影、同一内距），而正上方的链路组件写着「不是八个并列的功能，是一条从工位走到订单的路径」——**文案与视觉自相矛盾**。

**变更后**：

```
八大赋能 = 6 个链路节点（空间 → 算力 → 智能体 → 订单 → 流量 → 资本）
        + 2 项贯穿全链的支撑能力（集智商学院 · 企服超市）
```

| 位置 | 内容 | 形态 |
|---|---|---|
| 链路组件 | 6 个节点 + 「贯穿全链」支撑条（学院 / 企服为**可点击链接**） | 12px 圆角、描边无阴影（次级容器） |
| 卡片区 | **只展示 6 个链路模块**，3 列网格 | 16px 圆角 + 阴影的主卡（主卡连续排前，≤6 个） |

**8 个赋能详情页全部保留可达**（`/empower/{space,agents,compute,academy,enterprise,market,traffic,capital}`），其中学院与企服超市由支撑条链接进入。

**理由**：竞品审查（`docs/05` §6.2）认定集智唯一的差异化是「八大赋能是**一条链**」；视觉必须兑现文案。同时「8 张同款卡」正是「AI 生成感」的主要来源（`docs/06` §2.4）。

**编号变更**：卡片编号由「八大赋能原始编号 01–08」改为「**链路序号 01–06**」，与链路节点一一对应 —— 若沿用原始编号会出现 01→03→02→06 的跳号。

**单一事实源**：`src/lib/site/chain.ts`（`chainModules` / `supportModuleSlugs` / `allEmpowerSlugs`）。

## 3. 产品范围

### 3.1 本期范围（已确认）

| 范围项 | 结论 |
|---|---|
| 智能体 | **纯展示 + 外链跳转**，不建站内对话链路，不做试用 |
| 算力超市 / 企服超市 / 资本政策 / 流量超市 | 展示 + 申请留资 + 后台线索跟进 |
| 账号体系 | **不做登录、不做注册**；无用户中心、无社区互动 |
| 交付形态 | 需求文档 + 技术方案 + 可开工任务拆解 |

### 3.2 明确不在本期

- 站内智能体试用/多轮会话、模型参数配置、Token 计费与配额
- 供需市场的一对一实时撮合、订单流转、在线支付
- 用户注册/登录、评论区、点赞、关注、私信
- 算力券真实申领、企服真实下单、融资对接的真实系统打通
- 多语言、App、小程序

### 3.3 后续演进方向（写入技术方案预留接口即可，本期不实现）

`智能体站内试用` → `供需语义智能匹配` → `社区账号与互动` → `工作台/我的订单`

## 7. 设计规范

### 7.1 视觉基调

参照 `opcstore.com` 的结构与 `yzxcai.com` 的蓝色基调，结合品牌色板：

- 浅底为主（`#F6F9FC` / 白），深藏蓝用于深色区块与 Hero
- 卡片：白底、圆角 12–16px、轻投影、1px 细边框
- 主 CTA 实心主蓝；次 CTA 描边
- 数字指标用等宽/半粗大字号 + 青绿强调

### 7.2 布局

- 容器最大宽 1200–1280px，栅格 12 列
- 区块垂直节奏 96–128px（桌面）/ 56–64px（移动）
- 卡片网格：智能体 4 列（桌面）→ 2 列（平板）→ 1–2 列（移动）

### 7.3 3D / Shaders 动效规范

> 技术实现见 `docs/02-技术方案.md` 第 6 节。此处为产品侧约束。

| 编号 | 场景 | 位置 | 产品要求 | 优先级 |
|---|---|---|---|---|
| D-01 | Hero「众智星云」 | 首页首屏 | 表达「众智汇聚」，有生命感但不喧宾夺主；3 秒内进入稳态；不做全屏炫光 | P0 |
| D-02 | 八大赋能能量环 | 首页赋能区 | 鼠标/滚动驱动，8 张卡片 hover 时高亮对应环节点 | P1 |
| D-03 | 智能体卡片微动效 | 智能体列表 | 轻量 tilt + 光泽扫过，不影响点击与滚动 | P1 |
| D-04 | 数字指标滚动 | 首页指标条 | 数值从 0 滚动到目标值，仅首次进入视口时触发 | P1 |

**统一硬约束**：

1. 尊重 `prefers-reduced-motion`：开启时全部动效降级为静态（保留品牌渐变与图片）。
2. WebGL 不可用 / 低性能设备 / `Save-Data` 时自动降级为静态渐变或 CSS 动画，**不得报错、不得白屏**。
3. 3D 画布 `aria-hidden`，信息不依赖动效传达。
4. 3D 区域不阻塞 LCP：首屏文字与 CTA 先渲染，画布异步加载。
